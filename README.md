# OneOS-FakeRoot

A standalone Android **simulation** of root status and device identity. No real root access is provided or required.

## Features
- Toggle mock root profile
- Simulated Samsung Galaxy S26 Ultra identity
- Simulated SuperSU/Magisk permission prompt
- JSON profile display
- GitHub Actions debug APK build

**Important:** This app does not change Android system properties, execute su, provide root access, or affect detection by unrelated apps.

## Build
Run the **Build Android APK** GitHub Actions workflow, then download the `OneOS-FakeRoot-debug` artifact.
